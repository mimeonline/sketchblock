# Privacy

This notice applies to the Sketchblock project website and documentation at `https://mimeonline.github.io/sketchblock/`.

## Website and application are separate

| Surface | Relevant information |
| --- | --- |
| This project website | GitHub Pages hosting and the website analytics described below. |
| A self-hosted Sketchblock instance | The instance operator's hosting, account, board, logging, and retention configuration. |
| GitHub-connected boards | The configured GitHub account and repository, with GitHub's own service terms and privacy information. |

Reading these docs does not join a live board or connect a GitHub repository. For a self-hosted deployment, the operator should publish information about that installation's actual data handling and contact route. The [architecture](./architecture.md) and [backup guide](../operations/backup.md) describe where application data is stored.

## GitHub Pages hosting

The website is hosted by GitHub Pages. When a GitHub Pages site is visited, GitHub may process and store technical request data, including the visitor’s IP address, for security purposes. See the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) for details.

## Self-hosted analytics

The published website is configured to load self-hosted Rybbit from `stats.meierhoff-systems.de` for website usage statistics. The local Docusaurus development preview does not include this analytics script.

The [Meierhoff Systems privacy policy](https://meierhoff-systems.de/legal/datenschutz) describes the operator's privacy information. [Rybbit's privacy notice](https://rybbit.com/privacy) provides information about the vendor's own services; it is separate from the configuration and operation of this self-hosted analytics instance.

## Contact and complete privacy information

Meierhoff Systems operates the analytics service. Contact details, data-subject rights, and the complete privacy information are available in the [Meierhoff Systems privacy policy](https://meierhoff-systems.de/legal/datenschutz).

Questions about Sketchblock privacy can be sent to [sketchblock@meierhoff-systems.de](mailto:sketchblock@meierhoff-systems.de).
