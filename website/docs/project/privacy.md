# Privacy

This notice applies to the Sketchblock project website and documentation at `https://mimeonline.github.io/sketchblock/`.

## GitHub Pages hosting

The website is hosted by GitHub Pages. When a GitHub Pages site is visited, GitHub may process and store technical request data, including the visitor’s IP address, for security purposes. See the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) for details.

## Self-hosted analytics

For statistical evaluation and improvement of this website, I use the self-hosted analytics software Rybbit. Only anonymous usage statistics are stored. Rybbit does not set analytics cookies. Further information is available in the [Rybbit privacy information](https://rybbit.com/privacy).

## Contact and complete privacy information

Meierhoff Systems operates the analytics service. Contact details, data-subject rights, and the complete privacy information are available in the [Meierhoff Systems privacy policy](https://meierhoff-systems.de/legal/datenschutz).

Questions about Sketchblock privacy can be sent to [sketchblock@meierhoff-systems.de](mailto:sketchblock@meierhoff-systems.de).
